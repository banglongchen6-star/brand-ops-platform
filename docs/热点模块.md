## 一、模块定位

**一句话**：聚合全网热榜 + 自家音乐业务关键词打分，一站式筛选、收藏、拆解、送入候选池的内容选题入口。

**解决的问题**：
1. 运营每天要去抖音、小红书、B 站、微博……多个平台来回切，效率低
2. 非音乐相关的热点太多，需要一套音乐密码自己的"音乐相关度"打分规则
3. 收藏 / 拆解 / 入候选池的动作分散，希望集中在同一页完成

## 四、核心数据流

### 1. 拉取热榜（Sync）

```
前端「刷新」按钮
    └─▶ POST /api/content/hot-feed/sync
            ├─ 读取 content_platforms（source=dailyhot & enabled=true）
            ├─ 读取 content_keyword_library（enabled=true）
            ├─ 逐平台 GET https://api-hot.imsyy.top/{slug}
            │      ↓
            │   取前 50 条 → 计算 music_score → upsert
            │   （冲突键：platform_slug + external_id）
            └─▶ 返回 { synced_at, platforms[], total_upserted }
    └─▶ 前端 loadTrends() 刷新列表
```

### 2. 音乐相关度打分规则（`scoreMusic`）

```
基础分 0
for 每个关键词 in 启用关键词库:
    if 关键词出现在 (title + description) 中:
        if category === "negative":  score -= weight * 10
        else:                        score += weight *  8
最终分 clamp 到 [0, 100]
```

**默认关键词**（SQL 脚本已预置 14 条）：
- 🎵 音乐类 12 条：钢琴 / 吉他 / 乐器 / 唱歌 / 翻唱 / 乐谱 / 音乐 / 作曲 / 编曲 / 器乐 / 零基础学 / 练琴
- 🏷️ 自家品牌 1 条：音乐密码（权重 10）
- ⭐ 自定义 1 条：智能乐器（权重 7）

### 3. 单条热点交互

| 按钮 | 动作 | 落库字段 |
|------|------|---------|
| ⭐ 收藏 / 取消 | toggleStarred | `content_trends.starred` |
| 🧠 AI 拆解 | 展开卡片，Phase 3 将调用 Claude API | `content_trends.analyzed` |
| ➕ 候选 | addToPool | `content_candidate_pool` 新增行 |
| 🔗 外链 | 新窗口打开 | — |
| 展开卡片 | 同时自动 markRead | `content_trends.read = true` |

## 五、筛选逻辑（前端本地过滤）

按顺序应用到 `trends` 数组：

1. 子 Tab 筛选（starred / analyzed）
2. 平台 chips 多选（`selected.includes(platform_slug)`）
3. 音乐相关度开关（默认勾选，`music_score >= 70`）
4. 搜索框（title 子串匹配，不区分大小写）

无结果时：
- 如果 `trends.length === 0` → 提示"点刷新拉取 DailyHot"
- 否则 → "没有符合筛选条件的热点"

## 九、运营使用流程（推荐 SOP）

1. 每日早上点一次**🔄 刷新** → 拉取今日热榜
2. 勾选"音乐相关"开关（默认开），只看音乐度 ≥ 70 的条目
3. 扫卡 → 看上眼的点**⭐ 收藏** 或**➕ 候选**
4. 进 "我的收藏" → 对选中的点**🧠 AI 拆解**（Phase 3 上线后）
5. 拆解结果自动归入 "爆款库" + 套路库
6. 进候选池 → 组合生成选题 → 交给 AI 创作区（Phase 5）

## 十一、常见问题

**Q：刷新后卡片没变化？**
A：检查平台管理里 source=dailyhot 的平台是否启用；检查浏览器控制台 /api/content/hot-feed/sync 的返回。

**Q：某平台抓不到？**
A：DailyHot 上游间歇性不稳，接口返回的 `platforms[i].error` 会写明"上游 500"之类；重刷即可。

**Q：音乐度永远是 0？**
A：关键词库可能没启用（`enabled=false`），或者关键词与标题完全不匹配。在关键词库面板加一条自家领域词试试。

**Q：我想加一个 DailyHot 没覆盖的平台（公众号/视频号）？**
A：平台管理 → 新增平台 → 数据来源选"仅手动录入"。热点走"手动录入"子 Tab 录入（Phase 未开发，可用 SQL 先插）。
